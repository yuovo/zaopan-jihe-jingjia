# 早盘集合竞价

独立手机版早盘集合竞价选股工具。

- 每个交易日 09:25:02 后自动读取竞价并锁定结果。
- 09:25 数据不完整时在本次运行内自动补采，不等待整轮失败。
- 每只优选附带买入触发、仓位上限、硬止损、分批止盈和放弃条件。
- 15:00 后自动补最后收盘价，并标记封板、触板未封或未触板及原因。
- 提供排除创业板、科创板、北交所和 ST 的次日涨停候选，以及完整连板梯队。
- 保留上一交易日优选，并生成今日持仓处理建议。
- 创业板、科创板正常评分，进入前排时降级，由主板按分数递补。
- 页面仅提供量化筛选与盘面复盘参考，不构成投资建议。

手机使用：打开 GitHub Pages 地址，浏览器会进入 `index.html`，可添加到主屏幕。
